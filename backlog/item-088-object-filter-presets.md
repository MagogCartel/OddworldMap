# 88. Object filter presets

**Status:** closed — rejected, recorded so it is not re-proposed · **Effort:** n/a · **Where:** n/a · **Filed:** 2026-08-07 feature-ideation sweep

## What was proposed

One row of preset chips above the object-category checkboxes — *Speedrun* (doors/transitions + continue points), *100%* (Mudokons + portals), *Hazards only* — each just setting the existing checkboxes, which stay the source of truth.

## Rejected

No more furniture in the sidebar's filter block: the audiences a preset would serve are exactly the ones who already know which boxes to tick, so the chips would spend permanent space to save an expert three clicks — the sidebar equivalent of the corner-chrome restraint [72](item-072-copy-embed-code-button.md) records. Revisit only if real users are seen fumbling the checkboxes for one of these bundles.
