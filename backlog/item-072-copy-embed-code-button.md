# 72. Copy-embed-code button

**Status:** closed — rejected, recorded so it is not re-proposed · **Effort:** n/a · **Where:** n/a · **Filed:** 2026-07-24/25 review

## What was proposed

A button next to the copy-link one that copies a ready-made `<iframe>` snippet for `?embed=1`.

## Rejected

Embeds are not expected to be common, and the map's corner already holds three buttons — more chrome for a rare case. If embed adoption ever shows up in traffic, revisit.

**This is the standing reason the corner does not gain a fourth button**, and it has already been used as such once: [76](item-076-site-attribution.md)'s sketched icon button for the source link was declined partly on these grounds, and the About dialog opens from the sidebar footer instead. Anything proposing a new corner button inherits this argument.
